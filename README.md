# Netflix Clone (PHP + MySQL)

A full-stack Netflix UI clone built to practise server-side fundamentals.
It pairs a responsive Netflix-style landing page with a complete PHP
authentication system — user **registration**, **sign-in**, and a
**login-gated homepage** backed by a MySQL database.

### Features
- 🎬 Responsive Netflix-inspired landing page (HTML/CSS)
- 🔐 User registration & sign-in handled in PHP
- 🗄️ MySQL user store via a PDO/MySQLi connection
- 🚪 Session-based access to the home screen

### Stack
PHP · MySQL · HTML · CSS · JavaScript
